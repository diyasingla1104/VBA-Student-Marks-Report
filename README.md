# 🎓 Student Marks Report Automation (VBA Macro Project)

## 📘 Project Overview
This Excel VBA project automates the process of calculating students' total marks, percentage, and grade, and highlights those who fail (<40%).  
The project demonstrates data automation and visualization using simple VBA scripting.

## 🧩 Features
- Takes student marks from a sheet named **StudentMarks**
- Calculates **Total**, **Percentage**, and **Grade**
- Highlights failing students (<40%) in red
- Includes **two macros**:
  - `ResetStudentMarksReport` → clears old data and colors
  - `GenerateStudentMarksReport` → calculates and formats results
- Includes **buttons** on the sheet for one-click automation

## ⚙️ Tools Used
- Microsoft Excel (.xlsm)
- Visual Basic for Applications (VBA)

## 📁 File Included
- `Student_Marks_Report_Automation.xlsm` (main file)
- `README.md` (this documentation)

## 💡 How to Run
1. Download the `.xlsm` file.
2. Open it in Excel and **enable macros**.
3. Click:
   - 🧹 **Reset Sheet** → clears previous data  
   - 📊 **Generate Report** → calculates totals and highlights grades.
